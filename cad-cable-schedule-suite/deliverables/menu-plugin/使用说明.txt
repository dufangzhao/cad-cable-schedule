电缆表汇总 · CAD 插件（菜单版）
==================================================

插件形态：一个 CAD 菜单 + 设置对话框 + 命令行入口（CABLE_SUM / CBLSUM）：

    框选电缆表 → 菜单"电缆统计 → 统计选中电缆表" → 自动出 Excel

本包与前面的三个交付物（离线插件 / 网页服务 / agent skill）相互独立，可单独分发。


零、运行条件
============

不需要额外安装任何东西：

  · 不需要 Python   —— 引擎 cable-summary.exe 是单文件绿色版
  · 不需要联网 / 服务器 / 管理员权限
  · 需要 AutoCAD（2000 及以上；菜单功能需要 2013 及以上更稳）
  · 需要 Excel 或 WPS 才能"自动打开结果"；没装也能生成文件


一、安装（三步；第 1、2 步只需做一次）
======================================

1) 把整个 cad-plugin 目录放到任意位置，例如 D:\cable-summary\cad-plugin

2) 双击 cad-plugin\install.bat（一步到位：写配置 + 装成官方 Autoloader 插件）
   它把引擎路径写进配置，并打印三行确认：
       runner = D:\cable-summary\cad-plugin\run.bat
       engine = cable-summary.exe (ready)
       lsp    = OK (...cable-summary.ini)

（原第 3 步已合并进 install.bat，见上）
   它把插件装成 AutoCAD 官方 Autoloader 插件：整个插件被复制到
       %APPDATA%\Autodesk\ApplicationPlugins\CableSummary.bundle\
   并在 PackageContents.xml 里把 cable-summary-cad.lsp 声明为 AutoLISP 组件，
   同时把该目录加进受信任位置（TRUSTEDPATHS），免得每次启动都弹「未签名的可执行文件」。

4) 重启 AutoCAD。菜单栏最右边会自动出现「电缆统计」——不需要 APPLOAD，也不需要输入命令。

   原理：AutoCAD 每次启动都会扫描 ApplicationPlugins 目录，按里面的 PackageContents.xml
   自动加载声明的组件；本插件的 LISP 被加载时会自己把菜单建出来（COM 接口当场创建，
   不依赖菜单文件，并把系统变量 MENUBAR 设为 1——AutoCAD 2020 默认隐藏菜单栏）。
   同目录的 cable-summary.cuix 只是兜底，正常不需要手工 CUILOAD。

   （不想装成 bundle 也可以：在 AutoCAD 里 APPLOAD → 选 cable-summary-cad.lsp，本次会话就能用；
     但重启 CAD 后要重新加载——想一劳永逸，请用上面的 install.bat。）

装好之后，解压出来的这个 cad-plugin 目录可以删掉或挪到别处，插件照常工作：
   · 真正被 AutoCAD 加载的是 %APPDATA%\Autodesk\ApplicationPlugins\CableSummary.bundle 里那份
     **完整副本**（LISP / 对话框 / 引擎 / 配置全都在里面），运行时不读解压目录；
   · 设置也存在那份副本的 cable-summary.ini 里，删掉解压目录不会丢设置；
   · 卸载、自检同样用副本里的 uninstall.bat / check.bat，不需要原目录；
   · 要升级或重装时，用新的压缩包再解压一次、双击新的 install.bat 即可（设置会保留）。

卸载（两种）：
  · 双击 cad-plugin\uninstall.bat —— 删掉 ApplicationPlugins 里的 bundle，
    重启 AutoCAD 后菜单不再出现；插件目录本身留着或直接删掉都可以。
  · 菜单 电缆统计 → 卸载菜单：只把菜单从当前会话移除（插件仍在，重启后照旧出现）。


二、使用
========

1) 在图纸里框选要统计的多个电缆表（连表头一起框；可含图框）
2) 点菜单：电缆统计 → 统计选中电缆表
3) 结果 Excel 自动打开

结果文件默认保存在**桌面**；可用设置对话框改成指定目录。

菜单项说明：

    统计选中电缆表    统计当前选中的电缆表，输出 Excel
    统计设置…         打开设置对话框（见下）
    打开结果目录      用资源管理器打开上次结果的目录
    自检              直接运行 check.bat：弹出窗口显示 10 项自检报告（看完按任意键关闭）
    关于              显示版本、配置文件位置、引擎路径
    卸载菜单          把菜单从当前会话移除（命令 CABLE_SUM_MENU_REMOVE）
                      彻底卸载请双击 cad-plugin\uninstall.bat


三、设置（保存后永久生效）
==========================

菜单：电缆统计 → 统计设置…，弹出对话框：

  结果文件
    保存为：[________________] [浏览…] [用图纸目录]
    工程/图号：[______]
    [ ] 文件名加时间戳（避免覆盖同名文件）

  行为
    [x] 统计完成后自动打开 Excel

  各项含义：

    · 保存为：填的是**完整结果路径（含文件名）**，三种情况——
        · 留空 = 保存到桌面并自动命名（工程图号_电缆汇总表.xlsx）
        · 以 .xlsx 结尾 = 就用这个文件保存
        · 其他内容 = 当作目录，文件名自动命名
    · 浏览…：弹出保存对话框，**默认位置是桌面**、默认文件名 电缆汇总表.xlsx，
      可改成任意文件名；点「取消」不会改动已填内容（也不会报错）
    · 用图纸目录：一键填成当前图纸所在目录 + 电缆汇总表.xlsx
    · 工程/图号：拼在结果文件名最前面（工程图号_xxx.xlsx），**无论「保存为」填的是目录
  还是完整文件名都生效**；文件名里已经有这个工号时不会重复拼
    · 文件名加时间戳：默认关闭；即使重名，引擎也不会覆盖已有文件

设置会自动保存，**点一次「保存」以后一直有效**：
  · 存在插件的 cable-summary.ini 里，关掉 AutoCAD 再打开照样生效，不用重新设置；
  · **重新安装 / 升级插件也不会重置**这些设置（安装器会先把旧设置读出来、装完再写回）；
  · 改完设置下一次统计立即生效，不需要重启 AutoCAD；
  · 整个插件目录拷给同事时，设置也一起带过去。

（默认不写注册表、不写用户目录，卸载就是删文件夹。
  加载插件时自动完成的"开机常驻"只写两处：AutoCAD 受信任位置 TRUSTEDPATHS，
  以及用户支持目录里的 acaddoc.lsp 标记块；点菜单『卸载菜单』即可撤销，
  也可以执行命令 CABLE_SUM_AUTOSTART 再跑一次。）


四、汇总口径
============

  · 按 电缆型号 / 选用芯数 / 每芯截面(mm²) 三项合并分类
  · 同一类的多根电缆长度相加，得到该类总长度
  · Sheet 顺序：电缆汇总 / 备用电缆 / 明细 / 待确认 / _meta（隐藏）
  · 「电缆汇总」只有表头 + 各类别行，不再有「合计」行；列：电缆型号 / 选用芯数 /
    每芯截面(mm²) / 总长度(m) / 数量(根)
  · 合计数值写在隐藏 sheet「_meta」的 metadata（JSON 类型 bid-wisdom-pro）里：
    total_quantity / total_length
  · 终点标注"备用"的电缆单独成一个「备用电缆」sheet（表头与「电缆汇总」相同），
    不再排在汇总表下方，也不单独写「备用小计」行；备用电缆本来就不计入正式合计
  · 列宽按内容自动调整（中文按 2 个字符宽计算），保证单元格文字能在一行里完整显示、不被截断
  · 「明细」表：汇总行（S1、S2… 与备用 B1、B2…）/ 电缆型号 / 选用芯数 / 每芯截面(mm²) /
    总长度(m) / 电缆号（英文逗号拼接）；「待确认」表照旧
  · 图上未填长度的类别，总长度显示为"-"并在「待确认」表里提示


五、常见问题
============

现象                            处理
----------------------------    ------------------------------------------
装了菜单但菜单栏看不到          命令行 MENUBAR 回车，设为 1；
                                或重新执行一次 CABLE_SUM_MENU
CABLE_SUM_MENU 没反应           按命令行打印的中文提示定位是哪一步失败；
                                COM 创建失败时会自动改用 cable-summary.cuix
重启 CAD 后菜单没了             菜单默认每次启动都会自动出现。若没出现，多半是
                                插件目录被移动过——重新加载一次插件即可按新路径
                                重新常驻；也可能是之前用『卸载菜单』移除过
菜单点了没反应                  先跑一次 check.bat 看引擎是否就绪
提示找不到引擎                  双击 install.bat 重新写入路径
设置对话框不显示                确认 cable-summary-settings.dcl 与 .lsp 在同一目录
结果没自动打开                  检查设置里的"自动打开 Excel"是否勾选；
                                另外需要本机装了 Excel 或 WPS
未知命令 CABLE_SUM              插件没加载：重新 APPLOAD

排查工具：双击 cad-plugin\check.bat


六、技术信息
============

· 插件：AutoLISP（无需编译、无需 .NET）
· 菜单：由 CABLE_SUM_MENU 经 COM 动态创建（不依赖菜单文件；.cuix 仅作兜底）
· 对话框：DCL（AutoCAD 原生对话框定义）
· 引擎：cable-summary.exe（单文件，约 24 MB）
· 汇总口径与"离线插件 / 网页服务 / agent skill"共用同一份内核代码
