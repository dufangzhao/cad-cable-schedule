# 电缆汇总契约 `cable-summary`

面向“用户选中若干 CAD 电缆表 → 按型号/芯数/截面/长度汇总 → 出采购用 Excel”这一条固定流程。
本契约只规定汇总口径与输出结构；表的几何、列宽、字体等格式不在契约内。

## 汇总口径（固定）

- 汇总键是三项：`电缆型号`、`选用芯数`、`每芯截面mm²`；`长度(m)` 是求和项，不参与归类。
- **三项完全一致才归为一类**；任一项不同即新增一类，在 Excel 中新增一行；同类的 `长度(m)` 相加为 `总长度(m)`。
- 同一类别的`数量`等于该类覆盖的电缆记录条数（一行电缆记录算一根电缆）。
- 电缆号、起点、终点、线号、需用芯数、备注**不参与**合并判定，只作为明细证据保留。
- 图纸上的`-`、`--`、`/`、`无`与空白同义，都表示“明确未填”，不得当成有效值参与合并，也不得臆造为 0。
- 归一化只做等价合并，不改变显示：截面与长度按数值等价（`13`＝`13.0`＝`13.00`），型号按去空白、去大小写差异比较；
  写回 Excel 时仍使用图纸上的原始文本。

## 表识别

选中范围内可能同时包含电缆表、负荷计算表、图框和说明文字，必须按内容而不是按位置筛选：

- 以`电缆号`列头为锚点，取同一表头行内的列头集合。
- 只有同时具备`电缆号`、`电缆型号`、`选用芯数`、`每芯截面`、`长度`列头的表才认定为可汇总电缆表。
  例如只有`电缆号/起点/终点/最大需要容量/最高电压`的负荷表必须被排除，且计入 `metadata.candidate_tables` 供人工复核。
- 列归属边界取相邻列头 x 坐标的中点；不得用固定 x 偏移量硬编码列位置。
- 表头允许带空格等排版填充（`起 点`、`钢     管`），匹配前统一去空白。

## 行判定与文字换行

- 数据行以`电缆号`是否匹配`字母前缀+数字`判定，不依赖行距或网格线。前缀不限于 K/AK/TK，`UK1`、`F1` 等同样有效。
- 行高不固定、同一行内不同列的对齐点 y 可能相差数十个单位，因此按 y 容差聚类成行，容差取行距量级的一半。
- 单元格文字换行时会出现半行间距的续行簇：仅在“该簇没有电缆号”且“间距明显小于行距”时并入上一行，避免把两行真实记录误合并。
- 行距由相邻行 y 差的最小正众数估计，不写死数值。

## 状态与门禁

每个识别到的电缆表其`data_rows`、`pitch` 记入 `metadata.candidate_tables`，用于复核“读出的行数是否等于图上编号行数”。

以下情形必须进入 `issues`，不得静默通过：

| 情形 | 级别 | 处置 |
|---|---|---|
| 汇总键字段为空白或占位符 | `warning` | 按三项汇总键规则原样合并，并在待确认中列出该类别电缆号 |
| 电缆号只有号、型号/芯数/截面三项全空 | `warning` | 缺省不计入汇总，登记到`待确认`；`--keep-incomplete` 可改为单列一行计入 |
| 同一电缆号重复出现且参数不一致 | `conflict` | 阻断：分属两类的同一电缆号必须人工裁决 |
| 同一电缆号重复出现且参数一致 | `warning` | 提示可能是重复选表或两张表重复绘制 |
| 同一字母前缀编号范围内缺号 | `warning` | 提示可能存在未读出或原图缺失的行，数量会偏小 |

只有出现 `conflict` 时才阻断交付；`warning` 随 Excel 交付并逐条说明。

## JSON 模型

```text
schema_version: cable-summary
metadata: object            # 数据源、识别到的表数量、源行数、汇总行数、数量合计、跳过行
records: array              # 汇总行，字段固定：row_id, spec, selected_cores, core_section, length, quantity, cable_ids, key
issues: array               # issue_id, cable_ids, field, severity, message
source_rows: array          # 内部轨迹：每条电缆记录的来源表、电缆号、型号/芯数/截面与 handle
```

`key` 是三项（型号/芯数/截面）归一化后的比较键，用于证明“完全一致才合并”。`source_rows` 只留内部 JSON，不写进 Excel。

## XLSX 契约

工作表名称、列顺序和字段名固定：

- `电缆汇总`：`电缆型号`、`选用芯数`、`每芯截面(mm²)`、`总长度(m)`、`数量`。
  **只有表头 + 各类别行，没有`合计`行**；合计值只写在 `_meta` 的 `total_quantity` / `total_length`。
- `备用电缆`：表头与 `电缆汇总` 相同。终点标注"备用/预留"的电缆单独成表（`spare_records`），
  不计入 `电缆汇总` 的合计，也不写"备用小计"行；合计见 `_meta` 的 `spare_quantity` / `spare_length`。
- `明细`：`汇总行`、`电缆型号`、`选用芯数`、`每芯截面(mm²)`、`总长度(m)`、`数量`、`电缆号`；`电缆号`按英文逗号 `,` 拼接，禁止中文顿号。`电缆号`列必须可见，用于逐条对账。
- `待确认`：`issue_id`、`电缆号`、`字段`、`级别`、`问题`。
- `_meta`：隐藏，保存 `schema_version` 与元数据。

工作表顺序固定为 `电缆汇总` / `备用电缆` / `明细` / `待确认` / `_meta`。
每列宽度按该列最长内容自动计算（中文按 2 个字符宽），保证文字能在一行内完整显示；
内容超过 Excel 列宽上限（255）时该列自动换行，不截断、不隐藏。

汇总表不允许公式；数量必须是数字而不是文本。输出文件已存在时拒绝覆盖。
