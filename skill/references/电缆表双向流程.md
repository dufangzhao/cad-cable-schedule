# 电缆表双向流程

## 输入适配

- 端子 DWG/DXF：调用 `cad-terminal-diagram extract`，得到经验证的 `terminal-workbook`。
- 端子 XLSX：调用端子工作簿工具 validate/import。
- 多份输入：先合并为统一端子模型，保留每行来源；不得直接在聊天上下文中拼接表格。

## Extract

统一端子模型后查询项目电缆规则，生成类型、数字编号、显示占位、起点、终点、型号、需用/备用芯数、线号和方向证据。任何重复编号、相互矛盾方向或来源不完整项进入 `待确认`。

## Render

校验工作簿后，从每个类型 sheet 独立编译表块。业务 skill 计算所有行内容、容量分块和坐标，再提交 `cad-drawing`；底层执行器不推断 K/AK/TK 语义。

`scripts/生成电缆表绘图计划.py` 除了计划，还会在同目录写出 `cad_dispatch.json`
（`cad-dispatch`）与 UTF-8 侧车：`cable-annotations` 批次**默认始终外置**为
`@file:<绝对路径>`（不看批次大小），由 MCP 主机直接读取。执行时**只读该清单**，按 `index` 用
`action`+`params` 调用工具，不要把计划正文或侧车内容读进上下文重打；`view-result`
的 ZOOM 原生命令串与 `block_dyn` 的 `{{handle}}` 动态参数操作保持内联，必须先把
占位符替换为插块返回的真实 handle。需要重新生成时改计划后重跑生成器，不手改侧车。

```bash
# 编译计划 + 文件分发清单（纯文件；--no-dispatch 只出计划，--dispatch-output 换目录）
python scripts/生成电缆表绘图计划.py \
  --cable-model <cable-workbook.json> --rules <cable-layout-rules.json> \
  --source-dwg <模板.dwg> --save-as <目标.dwg> --origin 0,0,0 \
  --request-id <id> --output <plan.json> [--dispatch-output <目录>]
```

`cad-drawing` 返回 success 后仍需核对电缆业务条件，才能报告完成。


## Survey（选中电缆表 → 采购汇总表）

用户已在 CAD 中选中电缆表时，这是最短路径，不需要端子数据也不生成绘图计划：

1. `read_drawing_structure(scope="selected", scan_scope="modelspace")`，只读选择集，空选择/截断即失败关闭；
2. `python scripts/电缆汇总统计.py extract --input <artifact.json> --output-json <cable-summary.json> --output-xlsx <电缆汇总表.xlsx>`；
3. 按 `references/电缆汇总契约.md` 核对汇总行、数量合计与 `待确认`，再交付 Excel。

选择集里混有图框和说明文字是常态，脚本以`电缆号`列头为锚点、并要求 型号/芯数/截面/长度 四列列头齐全来认定电缆表；
负荷计算表一类“有电缆号但没有型号/芯数/截面/长度”的表会被排除并登记为不可用候选。

## Excel/CAD 对照边界

Excel sheet 与 CAD 电缆表块按页容量、字段顺序、空白编号行和视觉落位保持对照，但不得把 Excel 文件直接作为 CAD INSERT 或表格实体导入。Excel→CAD 和 CAD→Excel 都必须经过本 skill 的模型转换、知识库规则和 `cad-draw-plan`/结构化回读流程。
