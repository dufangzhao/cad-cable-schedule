# 电缆表块导入与连接数据填充

## 目标与固定规则

使用标准 `电缆表.dwg` 导入电缆表块，并将已审核的连接数据填入块外数据文字，形成可验收的电缆表。标准块内部的表格线、表头和格式以源 DWG 为唯一来源，不重复绘制或修改。

- 标准空电缆表位于 `raw/sources/CAD常用块/电缆表.dwg`。绘制电缆表时必须导入该 DWG，不重新绘制表格边框、表头或格式。每个电缆表实例都必须重新调用 `insert_dwg` 导入该资源；即使当前图纸中已有同名块定义，也不得改为复用同名定义。置信度：高（2026-08-18 用户确认）。
- 导入后的块定义名为 `电缆表`。该块是普通块，不是属性块，也不是动态块；块引用的属性数量和动态参数数量均为 0。因此不能通过 `manage_blocks set_attrs` 或 `block_dyn set` 填写数据。置信度：高。
- 电缆表实例的插入图层和块外数据文字均使用 `C-4`。标准块内部已封装的表格线、表头和格式以源 DWG 为准，不因本规则炸开或重绘。置信度：高（2026-08-21 用户确认）。
- 块内已封装完整表格线、表头、空白数据行及表格自身格式。只需在空白数据行上创建数据 `TEXT`，不需要炸开块，也不需要修改块定义。置信度：高。
- 跨柜连接识别与审核由 `cad-terminal-connectivity` 分支 C 负责，产出 `connection_graph` 或端子连接关系总表；`cad-drawing` 通用绘图分支 A 负责导入电缆表块、映射字段、创建数据文字、校验和保存。置信度：高。
- 电缆号、起点、终点、线号和需用芯数可由已审核的连接关系数据生成。选用芯数按固定档位规则由需用芯数确定；电缆型号、每芯截面、长度、钢管和备注属于项目工程参数，不得只根据端子连接关系臆造，必须来自项目资料、已批准参数表或用户确认。置信度：高。
- 选用芯数只能取固定值 `4`、`7`、`10`。设需用芯数为正整数 `n`，选用芯数取集合 `{4, 7, 10}` 中大于等于 `n` 的最小值：`1–4 → 4`、`5–7 → 7`、`8–10 → 10`。当需用芯数未知、无效或大于 `10` 时，没有可自动选择的合法档位，选用芯数应留空并转人工确认，不得外推其他数值。置信度：高（2026-08-17 用户确认）。
- 电缆记录按电缆号中字母前缀和数字部分进行自然排序，例如 `K1, K2, …, K10, K11`，不能使用纯字符串排序。
- 全局连接图中，同一电缆号下的多条 `connection_id_raw` 按各自连接记录顺序保存；同一电缆号允许跨多个目标柜和方向存在。生成电缆表时先按类型分表，再按 `(电缆类型, 数字编号)` 生成唯一显示行；同一类型同一电缆号只标一次，需用芯数等于该显示行获准连接记录数。置信度：高（2026-08-18 用户确认）。
- K/AK 常规填写源柜和目标柜柜编号，不附加端子排编号；TK 从 KB 引出时，起点例外填写 `KB柜号/具体通讯设备`，终点仍填写目标柜编号。输入为 `柜/端子排` 时，常规柜字段只取 `/` 前的柜编号。置信度：高（2026-08-18 用户确认）。
- 一个标准电缆表固定容纳 31 条电缆记录。超出时按自然排序连续拆分到多个完整表块，每个表块仍使用标准 DWG 重新导入；不延伸第 32 行、不拉伸、不炸开。置信度：高（2026-08-18 用户确认）。
- 数据 `TEXT` 使用图层 `C-4`、颜色 `ByLayer`、样式 `HZTXT`、字高 `3`、宽度因子 `0.8`、旋转角 `0`。线号字段使用 `middle_left`（Middle Left/左中），其他字段使用 `middle`（Middle Center/正中）。置信度：高（2026-08-18 用户确认）。
- 同一电缆发现重复线号时，绘图前必须列出重复值和关联端点并通知用户确认。用户确认继续且未指定其他展示方式时，表格只保留该线号第一次出现的位置；显示去重不自动删除连接记录，也不自动减少需用芯数。置信度：高（2026-08-18 用户确认）。
- 源柜未绘出且没有双侧参考时，反向生成记录仍保持 `candidate/draft` 证据状态。在 `conflict=0`、`unpaired=0` 且原记录、evidence handle、计算来源和设计规则来源齐全时，默认允许 `auto-if-clean` 进入正式图纸；不要求仅因 `candidate` 状态再次批准，也不得改写为 `confirmed`。置信度：高（2026-08-18 用户确认）。
- 电缆表位置不要求固定间距，必须以每个实际 `INSERT` 回读的真实 bbox 为最终依据。`local_bbox` 和 `block_step` 只能用于绘图计划预检，不能替代真实块尺寸；后续块的位置应按前一块实际 `xmax/ymax` 加安全间隙计算，并在填字前再次检查块间及块与既有实体的 bbox 不重叠。真实尺寸变化时，应按 handle 同步移动块和已创建文字，复核通过后才能继续。2026-08-21 实测标准 `电缆表.dwg` 实际宽度约 350.5，而经验间距 300 会重叠约 50.5，因此不得仅凭经验间距摆放。置信度：高。
- `Kx` 为控制电缆，`AKx` 为电源电缆，`TKx` 为通讯电缆；三类必须分别使用不同电缆表，不能混表。每类编号均从数字 `1` 开始独立按升序排列；已确认范围内缺失编号必须保留对应空白行，不写虚构连接，不把后续编号上移。置信度：高（2026-08-18 用户确认）。
- 起终点判定按“串联关系 >> KB 起点 >> DB/GB 起点（AK）>> 其他推断”执行。`Kx` 默认 `KB→其他柜`；`AKx` 无更强串联证据时以 DB/GB 为起点；`TKx` 通常从 KB 引出，起点填写 KB 内具体通讯设备。AK/TK 串联时按编号升序递归，前一电缆终点作为下一电缆起点；其他推断必须标记 `inferred` 并记录证据来源。置信度：高（2026-08-18 用户确认）。

## 证据与数据边界

- 数据分层为：连接识别与审核结果、工程参数、绘图执行结果。不得用连接关系替代电缆型号、截面、长度、钢管或备注等工程参数。
- 反向连接只有在证据完整且满足项目规则时才能进入正式图纸；进入正式图纸不等于将其证据状态改写为 `confirmed`。
- 同一电缆号可以跨多个目标柜。例如 `AK14` 在 `1AFE` 侧以 `3INU` 为目标柜，在 `3INU` 侧以 `1AFE` 为目标柜；两条方向性边均可保留。电缆表按类型和编号只显示一次，必须先解析唯一的起点和终点；无法解析时转人工确认。
- 针对以 `1KB` 为源柜的专项任务，只纳入有明确 `1KB` 方向证据的边；其他分柜之间的边保留在全局连接图，但不进入本次端子图或电缆表。
- 通用绘图执行器保持泛化，不把具体柜号、K 号或项目参数写死在 MultiCAD 工具中；专业字段语义和数据规则由知识库及上游连接模型提供。

## 阶段一：准备输入与定位标准块

1. 获取已审核的 `connection_graph` 或端子连接关系总表。
2. 确认不存在阻塞性 `conflict`。普通 `candidate` 和 `unpaired` 按项目规则处置；无双侧参考的受控反向方案满足证据完整、`conflict=0`、`unpaired=0` 时，默认允许 `auto-if-clean` 进入正式图纸，但保持 `candidate/draft` 证据状态。
3. 获取非连接工程参数：电缆型号、每芯截面、长度、钢管和备注。选用芯数由需用芯数按固定档位规则确定；其他缺失项不得猜测。
4. 通过 LLM Wiki 文件树定位当前项目中的 `raw/sources/CAD常用块/电缆表.dwg`，不要硬编码知识库根目录。

## 阶段二：插入标准电缆表块

1. 新建或切换到目标图纸，并用 `manage_files list/switch` 确认活动文档。
2. 每个电缆表实例都使用 `insert_dwg` 重新导入 `电缆表.dwg`，记录返回的真实块引用 handle；即使图内已有同名块定义也不复用。
3. 回读验证：
   - `manage_blocks get_attrs|handle`：应为 0 个属性；
   - `block_dyn get|handle`：应为空；
   - `read_drawing_structure`：应存在块定义 `电缆表`，模型空间存在对应 `INSERT`。
4. 保留块引用，不炸开，不修改块定义。块内表格几何、表格线、表头和既有格式均以源 DWG 为准。
5. 多块连续布置时，插入一个、回读一个真实 bbox；按实际 extents 加安全间隙确定下一块位置。全部块通过 bbox 检查后，才创建块外数据文字。

## 阶段三：整理连接数据与生成显示行

1. 识别电缆类型 `K`、`AK`、`TK`，按类型拆分数据集，分别使用不同电缆表。
2. 每类提取数字编号范围，从 `1` 开始自然排序；范围内缺失编号保留空白占位行，不压缩行序。
3. 每个已出现的类型/编号只生成一行数据：
   - 电缆号：类型加数字，例如 `K1`、`AK1`、`TK1`；
   - 起点和终点：按[[电缆类型与起终点判定]]解析；K/AK 常规写柜号，TK 的 KB 起点写 `KB柜号/具体通讯设备`；
   - 线号：按记录顺序连接各 `connection_id_raw`，统一使用英文逗号 `,` 分隔，禁止使用中文顿号 `、`；
   - 需用芯数：该组有效连接记录数；
   - 选用芯数：从 `4`、`7`、`10` 中选择大于等于需用芯数的最小值；无合法档位时留空并转人工确认；
   - 其余字段：来自项目资料、已批准参数表或用户确认。
4. 全局连接图允许同一电缆号存在多个目标柜，但电缆表按类型/编号只显示一次。只有空目标柜、目标端重复、方向互斥、编号重复或起终点无法解析时，才停止绘制并转人工确认。
5. 同一电缆出现重复线号时，绘图前列出重复值和关联端点并通知用户确认。用户确认继续且未指定其他展示方式时，线号单元格只保留该值第一次出现的位置。显示去重不改变连接记录和需用芯数，除非用户确认上游记录本身重复并批准删除或合并。

## 阶段四：向标准块空白行填值

### 坐标与容量

- 块插入基点记为 `(bx, by)`，比例为 `s`，旋转为 0 时，数据行使用块局部坐标换算为世界坐标；若块有旋转或非 1 比例，应使用块变换矩阵计算，不直接相加。
- 第一数据行中心相对块基点约为 `y = 213.5`，后续行每行向下递减 7；第 `i` 行局部中心为 `y_i = 213.5 - 7 × (i - 1)`。
- 单表合法行号固定为 `i=1..31`。每种类型分别按编号序列切分；记录数或空白占位行超过 31 时，只在同一类型内为每批重新导入一个完整电缆表。不得把第 32 行写到块外，不得跨类型拼表、拉伸、炸开表块或缩小文字。
- 各字段局部落点如下：

| 字段 | 局部 X 坐标 |
|---|---:|
| 电缆号 | 7.75 |
| 起点 | 25.25 |
| 终点 | 45.25 |
| 线号 | 57.25 |
| 需用芯数 | 180.25 |
| 电缆型号 | 200.25 |
| 选用芯数 | 220.25 |
| 每芯截面 | 240.25 |
| 长度 | 260.25 |

上述坐标是数据填充接口，不是重新绘制表格的格式规范；以标准块当前版本为准。若块版本变化，必须重新结构化读取块内网格后再填值。

### 创建数据文字

1. 使用 `draw_entities` 批量创建 `TEXT`，减少往返。
2. 所有数据 `TEXT` 使用图层 `C-4`、颜色 `ByLayer`、样式 `HZTXT`、字高 `3`、宽度因子 `0.8` 和旋转角 `0`。
3. 线号字段使用 `middle_left`；其他字段使用 `middle`。钢管直径、钢管长度和备注为空时不创建文字。
4. 表块位置可根据现有图形灵活选择，不要求固定间距；但必须先按真实 `INSERT` bbox 计算安全位置，再创建块外文字。若发现重叠，只修复受影响块和文字并重新回读，不能以最终截图替代结构 bbox 验收。

## 阶段五：验收与保存

1. 结构化核对模型空间：按 K/AK/TK 分别计算电缆表 `INSERT` 数量（含编号空白占位行）；确认每个实例都来自一次独立 `insert_dwg`，并包含预期数量的数据 `TEXT`。
2. 按电缆号逐行重建字段，与绘制前的预期数据逐项比较。
3. 按 K/AK/TK 分别核对：从 1 开始的编号连续占位、自然排序、同类型同编号唯一性、起点和终点方向、线号数量与需用芯数的一致性；确认选用芯数属于 `{4, 7, 10}` 且为不小于需用芯数的最小合法档位；确认缺失编号行不包含虚构连接。
4. 精确核对通过后执行最终视觉验收，检查表格完整、分表顺序连续、文字落格、无越界、重叠、遮挡、缺行或乱码。
5. 另存到用户指定路径；除非明确要求，不覆盖标准块源文件。

## 失败处理与经验边界

- 将标准参考电缆表当作普通图纸并重新解析、修改其中已有文字对象时，原因通常是未先检查知识库 `CAD常用块` 目录中的标准块资源。绘图前应通过 LLM Wiki 文件树查询 `raw/sources/CAD常用块`，优先导入标准块，再判断填值接口。
- 不得仅凭“块对象”名称假设电缆表块可通过属性 TAG 填值。插入后必须回读 `get_attrs|handle`、`block_dyn get|handle` 和块定义结构；本块属性数与动态参数数均为 0，正确方案是在块外创建数据 `TEXT`。
- 不得把表格边框、表头或块内格式再次沉淀为绘制规则。表格几何、表格线、表头和块内既有格式以块文件为唯一来源；块外数据文字的图层、样式、字高、宽度因子和对齐规则按本页确认参数执行。
- 不得从连接关系推导电缆型号、截面或长度。缺少工程参数时列为待确认，不写入正式图纸。
- 不得只检查工具返回的 `success=true`。批量绘制可能出现字段错位、漏行或样式不一致；执行后必须重读图纸结构，逐行重建数据并与预期表比较，再进行最终视觉验收。
- 块插入和数据文字创建应保存每次实际返回的 handle，不得按 handle 连续性推算对象。

## 内容边界

本页只保留电缆表标准块导入、连接数据整理、块外数据文字填充和验收规则，不写入具体项目柜号、K 号或工程参数。项目连接明细和参数应分别来自已审核的连接关系数据、项目资料或用户确认。

## 执行偏好

- 面向 Agent 的路由和流程说明使用中文；工具名、字段名和命令可保留英文。
- 电缆表的表格几何、表格线、表头和块内既有格式不重复写入知识库，以 `raw/sources/CAD常用块/电缆表.dwg` 为唯一格式来源；块外数据 `TEXT` 格式按本页确认规则执行。
