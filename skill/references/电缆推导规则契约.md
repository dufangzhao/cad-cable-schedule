# 电缆推导规则契约 `cable-derivation-rules`

知识库查询结果先物化为规则 JSON，再交给确定性脚本；脚本不得读取聊天摘要推断规则。

必填字段：

| 字段 | 含义 |
|---|---|
| `schema_version` | 固定 `cable-derivation-rules` |
| `cable_id_pattern` | 含命名组 `type` 和 `number` 的完整匹配正则 |
| `type_aliases` | 捕获类型到 `K|AK|TK` 的映射 |
| `start_priority` | 起点柜号正则，按优先级排列 |

可选字段：

- `max_number_by_type`：确认编号范围；大于实际最大编号时补 blank 行。
- `default_spec_by_type`：各类默认型号。
- `spare_cores_by_type`：各类备用芯数。
- `include_start_device_for_types`：起点需附具体设备的类型，例如通讯电缆。

所有正则最长 512 字符并使用超时匹配。规则 JSON 的来源页面写入输出 metadata。
