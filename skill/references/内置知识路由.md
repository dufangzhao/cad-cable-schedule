# 电缆表知识来源路由

## 默认路径

用户未指定知识来源时，使用本 skill 自带的 `references/内置知识/2026-08-13-电缆表块导入与连接数据填充.md`，不依赖 LLM Wiki。该文档覆盖标准电缆表块导入、数据填充、K/AK/TK 分类以及起终点判定。

按任务关键词读取最小必要内容；不要因为调用 `cad-drawing` 而加载端子图专业文档。

## LLM Wiki 路径

用户明确指定“知识库/LLM Wiki/我的知识库”，或调用方传入 `knowledge.source=llm-wiki` 时，使用 LLM Wiki 页面作为本次唯一业务知识来源，并记录页面路径。Wiki 查询失败时停止，不降级到本地内置知识。

调用方已提供完整规则和编译参数时使用 `knowledge.mode=caller-provided`，不重复查询。用户明确跳过所有知识时使用 `knowledge.mode=user-skip`。

## 冲突处理

内置文档、Wiki 页面和调用方规则不得在同一任务中静默混用。发生冲突时列出来源与字段并阻断，交由用户或调用方裁决。
