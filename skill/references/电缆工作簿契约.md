# 电缆工作簿契约 `cable-workbook`

## Sheets

- 每个实际 CAD 电缆表块对应一个工作表，命名为 `{类型}_{页码}`，例如 `K_1`、`K_2`、`K_3`。
- 工作表数量由实际需要绘制的标准块数量决定；不是固定的 K/AK/TK 三张表。
- 单个 sheet 固定对应一个标准电缆表块的 31 行数据，因此包含 1 行表头 + 31 行数据。
- `待确认`：冲突、方向不明和需要用户决定的事项。
- `_meta`：隐藏 sheet，保存 schema_version、来源元数据和 block/sheet 映射。

## 电缆表 sheet 列

固定顺序：`电缆号`、`起点`、`终点`、`线号`、`需用芯数`、`电缆型号`、`选用芯数`、`每芯截面mm²`、`长度(m)`、`钢管直径(mm)`、`钢管长度(m)`、`备注`、`置信度`、`状态`、`问题与待确认`。

`row_id`、`row_kind` 和 `source_terminal_row_ids` 为隐藏技术列；Excel 不再显示“电缆类型”和“数字编号”，这两个字段由 sheet 名和 `电缆号` 解析恢复。`row_kind=data|blank`；blank 表示对应 CAD 标准块中的空白编号行，业务字段必须为空。每个 sheet 的 31 行必须与对应 CAD 标准块逐行对照，不能只输出非空数据行。

`线号`列默认左对齐并保持单行显示，其余业务列默认居中。`选用芯数`按知识库固定档位推导；工程依据不足的电缆型号、截面、长度、钢管和备注保持为空。方向置信度为 `high|medium|low|unknown`，状态为 `confirmed|candidate|conflict|unpaired`。

## 待确认列

固定顺序：`issue_id`、`row_id`、`字段`、`级别`、`问题`。级别为 `warning|blocking`。

## JSON 模型

```text
schema_version: cable-workbook
metadata: object
records: array
issues: array
```

线号和源端子 row_id 在 JSON 中使用数组；导出 XLSX 或 CAD 显示文本时统一使用英文逗号 `,` 分隔，禁止使用中文顿号 `、`。语义字段不允许公式。视觉格式可以调整，但 sheet 命名、页容量、列顺序、技术 ID 和 schema_version 不得改变；Excel 与 CAD 标准块只要求按同一页容量、字段顺序、编号空位和视觉落位进行对照；Excel 不能直接导入 CAD。任一方向的转换都必须由 `cad-cable-schedule` 结合知识库规则重新生成 `cable-workbook` 或 `cad-draw-plan`，再由 `cad-drawing` 执行。
