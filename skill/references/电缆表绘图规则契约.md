# 电缆表绘图规则契约 `cable-layout-rules`

把知识库中与当前图纸匹配的表块、容量、坐标和文字规则物化为 JSON。脚本不内置任何项目坐标。

必需字段：

- `knowledge_sources`：实际采用的知识库页面路径。
- `layers`：图层的 `name`、`color`、`lineweight`；可为空数组。
- `types`：只需包含本次出现的 `K`、`AK`、`TK` 类型。
- `types.<type>`：`source_dwg`、`capacity`、`origin_offset`、`block_step`、`local_bbox=[xmin,ymin,xmax,ymax]` 和 `row_layout`；可选 `insertion_offset`、`scale`、`rotation`、`dynamic_parameters`。
- `row_layout`：`first_row_offset`、`row_step` 和 `columns`。
- `columns[]`：`field`、`offset`、`height`；可选 `color`、`layer`、`rotation`、`style`、`width_factor`、`alignment`。空值不生成文字实体。
- `view_margin`：最终视图边界余量。

`dynamic_parameters` 的值可以是常量，也可以使用 `$row_count`、`$capacity`、`$cable_type`、`$block_number`。允许的文字字段为 `cable_id`、`start`、`end`、`wire_numbers`、`required_cores`、`spec`、`selected_cores`、`core_section`、`length`、`conduit_diameter`、`conduit_length`、`remark`、`direction_confidence`、`issue`；`row_id`、`row_kind`、`cable_type`、`number` 和 `source_terminal_row_ids` 仅作为内部技术字段，不直接绘制。

编译器按类型和数字编号排序，再按标准块容量切成完整表块；Excel sheet 与 CAD block 使用同一页分块结果，但转换仍由 skill/知识库重新编译，不直接导入 Excel。所有文字合并为一次批量绘制。任何未确认记录、blocking issue、数据行方向未知、重复/断裂编号、缺少类型规则或估算 bbox 重叠都会阻断绘图。`local_bbox/block_step` 仅用于计划预检；执行阶段每个 INSERT 必须按真实 handle 回读 bbox，后续块按真实 extents 加安全间隙定位，全部块通过块间/块与既有实体的真实 bbox 检查后才能创建 TEXT。若实际 bbox 与估算不同，必须先按 handle 修正块及其文字位置并重新回读。
